# Claude activity panel

[English](README.md) | **한국어** | [日本語](README.ja.md)

**내가 물어본 걸 Claude 가 다 답했나? 그리고 실제로 뭘 바꿨나?**

긴 코딩 세션에서는 내 질문이 몇 페이지짜리 출력에 묻히고, "완료했습니다" 라는 말만으로는 바뀐 코드가 이제 어떻게 동작하는지 알기 어렵습니다. 이 패널은 [cmux](https://cmux.dev) 나 Orca 의 [Claude Code](https://claude.com/claude-code) 패널 옆에 붙어서, 턴마다 이 두 가지를 보여줍니다.

- **Q&A 점검**: 한 턴에 보낸 질문과 요청을 모두 뽑습니다. Claude 가 작업하는 중에 보낸 메시지도 포함됩니다. 각 항목을 Claude 가 실제로 한 말과 행동에 비춰 답변됨 / 일부 / 미답변으로 판정하고, 빠진 부분은 하이라이트합니다. 답을 못 받은 항목은 이후 턴에서 답하면 다시 대조해 갱신합니다. 상태를 직접 바꾸거나 보관할 수 있고, 페이지에서도 `claude-qa` 명령으로도 됩니다. 답을 못 받은 항목은 **↩ 다시 물어보기** 로 다시 묻는 문장을 클립보드에 복사해 Claude 에 붙여 넣을 수 있습니다 (cmux 소켓 비밀번호 모드가 켜져 있으면 패널에 바로 입력됩니다. 그렇지 않으면 cmux 가 자기 하위 프로세스의 요청만 받기 때문입니다).
- **로직 흐름**: 파일을 고친 턴이 끝나면, 바뀐 기능을 실행 순서대로 펼쳐 보여줍니다. 단계별 파이프라인, 각 단계가 하는 일과 바뀐 점, 바뀐 줄이 하이라이트된 실제 코드 발췌, 바뀐 파일, 실행된 검증이 들어갑니다.
- **실시간 활동**: Claude 가 쓰는 도구(실행 중, 성공, 실패, 걸린 시간)와 고친 파일을 바로바로 보여줍니다.

패널 화면과 분석 결과는 영어, 한국어, 일본어를 지원합니다.

## 동작 방식

```
Claude Code hooks ──► record.sh ──► logs/<pane>.jsonl ──┐
   (도구 호출, 요청, 턴 종료)                           ├─► server.py (127.0.0.1:47821) ──► 브라우저 패널의 app.html
Stop hook ──► flow.py / qa.py ──► flows/, qa/ (JSON) ───┘
                 └─ headless `claude -p` (읽기 전용 도구, MCP/hook/CLAUDE.md 없음)
```

- 실시간 화면은 비용이 들지 않습니다. hook 이 JSON 한 줄씩 기록하고 페이지가 로컬 서버를 1초마다 읽습니다.
- 흐름과 Q&A 는 턴이 끝난 뒤 따로 도는 headless `claude -p` 라서 작업 중인 세션의 컨텍스트를 건드리지 않습니다. 흐름은 파일을 고친 턴에만 돌고 Read/Grep/Glob 로 코드를 읽을 수 있습니다. Q&A 는 대화 텍스트만 봅니다.
- 패널 키는 cmux 패널 id, 없으면 Orca pane 키, 없으면 세션 id 입니다. Q&A 는 세션별로 저장되고 현재 세션만 보여줍니다.
- cmux 에서는 패널 오른쪽에 브라우저 split 으로 열립니다. Orca 에서는 브라우저 탭으로 열립니다 (Orca 에는 브라우저 split 이 없습니다).

## 요구 사항

macOS, Claude Code, `jq`, `curl`, `/usr/bin/python3` (3.9 이상, 표준 라이브러리만. `xcode-select --install` 로 설치됨), zsh, 그리고 cmux 또는 Orca.

## 설치

```sh
git clone <이 저장소> ~/.claude/activity-panel
~/.claude/activity-panel/install.sh
```

`install.sh` 는 `~/.claude/settings.json` 에 hook 을 추가하고 (바뀌는 것이 있을 때만, 옆에 백업을 남김), `~/.zshrc` 에 표시된 블록을 붙이고, `claude-panel`, `claude-flow`, `claude-qa`, `claude-activity` 를 `~/.local/bin` 에 넣습니다. 다시 실행해도 바뀌는 것이 없습니다.

## 명령

터미널에서 실행하거나, Claude Code 안에서는 앞에 `!` 를 붙여 실행합니다 (예: `! claude-panel`).

| 명령 | 하는 일 |
|---|---|
| `claude-panel` | 이 패널의 사이드 패널 숨기기 / 보이기 |
| `claude-flow` / `claude-flow all` | 이 패널 / 모든 패널 목록을 기본 브라우저 전체 화면으로 열기 |
| `claude-qa list [--open]` | 현재 세션의 질문을 id 와 상태와 함께 보기 |
| `claude-qa set <id> answered\|partial\|unanswered\|auto` | 상태 직접 지정 (`auto` 는 모델 판정으로 되돌리기) |
| `claude-qa archive <id>` / `restore <id>` | 항목 보관 / 복원 |
| `claude-activity` | 실시간 화면을 이 패널의 터미널 UI 로 보기 |

패널 안 단축키: `1` `2` `3` 으로 흐름, 실시간, Q&A 탭 전환, `←` `→` 로 흐름 단계 이동, `?` 로 모든 명령과 설정이 담긴 도움말 열기.

## 설정

패널 오른쪽 위 **⚙ 설정** 에서 바꿉니다. `~/.claude/activity-panel/config.json` 에 저장되고 다음 분석부터 바로 적용됩니다. 재시작은 필요 없습니다.

**적용 범위** 에서 **모든 패널** 을 고르면 기본값이 바뀌고, **이 패널만** 을 고르면 이 패널(과 그 안에서 도는 Claude 세션)에만 덮어씁니다. 예를 들어 한 패널은 일본어, 다른 패널은 한국어로 쓸 수 있습니다. 패널별 값은 설정 창에 표시되고 전체 설정을 따르도록 되돌릴 수 있습니다.

| 설정 | 기본값 | 의미 |
|---|---|---|
| 분석 모델 | `opus` | 흐름과 Q&A 분석 모델 (`opus`, `sonnet`, `haiku` 또는 전체 모델 id) |
| 언어 | `en` | 패널 화면과 분석 결과 언어: English, 한국어, 日本語 |
| 흐름 자동 생성 | 켜짐 | 끄면 ↻ 버튼으로만 만듦 |
| Q&A 자동 점검 | 켜짐 | 끄면 ↻ 버튼으로만 점검 |
| 세션 시작 때 패널 열기 | 켜짐 | 끄면 `claude-panel` 로만 열기 |

환경변수는 `CLAUDE_PANEL_PORT` (기본 `47821`) 하나뿐입니다.

## 자주 묻는 질문

**Claude 를 추가로 몇 번 호출하나요?**
턴이 끝날 때마다 최대 2번입니다. Q&A 점검이 매 턴 1번, 그 턴에 파일을 고쳤으면 로직 흐름이 1번 더 돕니다. 실시간 화면, 상태 변경, 보관은 호출하지 않습니다. `!` 셸 명령은 턴이 아니라서 아무것도 실행되지 않습니다. ↻ 버튼은 누를 때마다 1번입니다.

**비용은 얼마인가요?**
측정값: Q&A 점검은 Opus 로 $0.04 ~ $0.11, 로직 흐름은 Sonnet 으로 $0.16 ~ $0.17 (Opus 는 아직 측정하지 않음). 흐름은 읽는 코드가 많을수록 비싸집니다. 이 금액은 Claude Code 가 보여주는 정가 기준 추정치이고, 구독 요금제에서는 대신 사용량 한도에 잡힐 것으로 보이지만 확인하지는 않았습니다. 줄이려면 모델을 `sonnet` 이나 `haiku` 로 바꾸거나 자동 실행을 끄면 됩니다.

**Claude 가 매번 HTML 을 만드나요?**
아닙니다. 페이지 템플릿은 하나뿐입니다. 분석은 JSON 을 돌려주고 페이지가 그걸 그립니다.

**↻ 다시 만들기 / ↻ 다시 점검은 에이전트 호출인가요?**
네. 자동 실행과 같은 headless `claude -p` 를 띄우고 비용도 같습니다. 파일을 읽을 수만 있고, 고치거나 명령을 실행하지는 못합니다.

**작업 중인 세션이 느려지거나 컨텍스트가 늘어나나요?**
아닙니다. 분석은 턴이 끝난 뒤 별도 프로세스로 돌고 세션 컨텍스트에 아무것도 더하지 않습니다.

**로직 흐름이 코드 로직에도 동작하나요?**
그게 목적입니다. 바뀐 기능을 실행 단계로 펼치고 현재 파일에서 실제 코드를 발췌해 보여줍니다. 파일을 고친 턴에만 자동으로 돌고, 설명만 한 턴은 ↻ 를 누르면 됩니다.

**나중 턴에서 답했는데 아직 일부로 나와요.**
각 턴은 그 턴의 답변으로 판정합니다. 턴이 끝날 때 같은 세션의 이전 턴에서 답을 못 받은 항목(최대 20개)을 그 턴과 다시 대조해, 답했으면 올려 줍니다. 더 오래된 항목은 그 질문의 "↻ 이 질문만 다시 점검" 을 누르거나 상태를 직접 바꾸세요.

**패널을 숨기거나 끄려면?**
`claude-panel` 로 숨기거나 보입니다. 저절로 열리지 않게 하려면 "세션 시작 때 패널 열기" 를 끕니다. 제거하려면 `uninstall.sh` 를 실행합니다 (`--purge` 를 붙이면 기록과 설정까지 지움).

**데이터는 어디에 저장되나요?**
`~/.claude/activity-panel/` 아래에 있습니다: `config.json` (설정), `logs/` (도구 활동), `flows/` (로직 흐름), `qa/<패널>/<세션>/` (Q&A, 세션별 보관), `qa/<패널>/overrides.json` (직접 바꾼 상태). 모두 git 에 올라가지 않습니다. 패널 페이지 주소는 `http://127.0.0.1:47821/p/<패널>`, 모든 패널 목록은 `http://127.0.0.1:47821/` 입니다.

## 데이터와 개인정보

모든 데이터는 내 컴퓨터에, 내 계정만 읽을 수 있는 파일로 있습니다. 서버는 127.0.0.1 에서만 열리고, `127.0.0.1` 이나 `localhost` 로 온 요청만 받으며 (그래서 웹 페이지가 DNS rebinding 으로 접근할 수 없음), POST 요청에는 `X-Claude-Panel` 헤더가 필요해서 다른 웹 페이지가 설정을 바꾸거나 유료 분석을 실행시킬 수 없습니다.

## 제거

```sh
~/.claude/activity-panel/uninstall.sh          # 기록한 데이터와 설정은 남김
~/.claude/activity-panel/uninstall.sh --purge  # 그것까지 삭제
```

## 확인하지 못한 것

Orca 경로(`orca tab create`)는 처음부터 끝까지 실행해 보지 못했습니다.
